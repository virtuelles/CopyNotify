# CopyNotify

常常按了 Ctrl+C 卻沒有真的複製成功，結果 Ctrl+V 貼上的是以前複製的內容？

CopyNotify 是一個常駐在系統匣的 Windows 小程式。**剪貼簿成功更新時**，它會在畫面上跳出提示，並顯示這次複製到的內容。按了 Ctrl+C 卻沒看到提示，就代表沒有複製成功。

## 功能

- 監聽 Windows 剪貼簿更新事件（`AddClipboardFormatListener`），只有剪貼簿內容真的改變時才會提示。
- 依內容類型顯示預覽：
  - **文字**：內容（最多 8 行）與字數
  - **檔案**：檔名清單與數量
  - **圖片**：縮圖與尺寸
- 複製的內容與上一次相同時，會標註「與上次相同」。
- 提示不搶焦點、滑鼠可直接點穿，約 1.4 秒後淡出，不會打斷正在做的事。
- 多螢幕：提示出現在目前使用中視窗所在的螢幕。
- 可自由設定提示位置（見下方）。
- 單一執行檔，不需安裝任何執行環境（使用 Windows 內建的 .NET Framework 4）。

右鍵複製、選單複製等其他方式也會觸發提示，因為它偵測的是剪貼簿有沒有更新，不是有沒有按 Ctrl+C。

## 系統需求

- Windows 10 / 11
- .NET Framework 4.x（Windows 10 以上已內建）

## 編譯

不需要安裝 Visual Studio 或 .NET SDK。直接執行：

```bat
build.bat
```

它會用 Windows 內建的 `csc.exe`（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\`）編譯出 `CopyNotify.exe`。

## 使用方式

執行 `CopyNotify.exe` 後，畫面上會出現「複製提示已啟動」，右下角系統匣會多一個綠色打勾圖示。之後每次成功複製都會跳出提示。

在系統匣圖示上按右鍵可以：

| 選項 | 說明 |
|---|---|
| 暫停提示 | 暫時不顯示提示 |
| 提示位置 | 設定提示出現的位置（見下方） |
| 開機時自動啟動 | 寫入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，登入時自動執行 |
| 結束 | 關閉程式 |

### 提示位置

- **九個預設位置**：左上、上方中央、右上、左側中央、正中央（預設）、右側中央、左下、下方中央、右下
- **跟隨滑鼠游標**：顯示在游標右下方，靠近螢幕邊緣時會自動換到另一側
- **自訂位置（拖曳調整）**：畫面上會出現可拖曳的提示框，按住左鍵拖到想要的位置，**雙擊左鍵**儲存，**按右鍵**取消

位置以「在螢幕上的相對位置」儲存，所以提示框大小不同、或出現在不同解析度的螢幕上時，靠邊對齊的效果都會維持。設定存在登錄檔 `HKCU\Software\CopyNotify`。

> 如果開啟了「開機時自動啟動」之後才搬動 `CopyNotify.exe`，請重新勾選一次。

## 自訂外觀

提示的停留時間、行數、顏色與字型都寫在 `CopyNotify.cs` 中 `Overlay` 類別開頭的常數：

| 常數 | 說明 | 預設 |
|---|---|---|
| `HoldMs` | 提示完整顯示的時間（毫秒） | 1400 |
| `FadeMs` | 淡出時間（毫秒） | 400 |
| `MaxBodyLines` | 文字預覽最多顯示行數 | 8 |
| `EdgeMargin` | 與螢幕邊緣的距離（px） | 24 |
| `CursorOffset` | 跟隨游標時與游標的距離（px） | 18 |

修改後重新執行 `build.bat` 即可。

## 移除

1. 系統匣右鍵 → 取消「開機時自動啟動」→ 結束
2. 刪除 `CopyNotify.exe`
3. （選擇性）刪除登錄檔機碼 `HKCU\Software\CopyNotify`
